## ⚖️ Legal Enforcement

If someone violates your license:

1. **Document the Violation**
   - Screenshot their repo/site
   - Save their code
   - Note the date

2. **Send a Cease & Desist**
   - Polite email explaining the violation
   - Request they remove your code or get a license
   - Give them 14 days to comply

3. **GitHub DMCA**
   - File a DMCA takedown notice with GitHub
   - GitHub will remove the infringing repo

4. **Legal Action (if needed)**
   - Creative Commons has legal resources
   - Copyright infringement is enforceable in most countries
   - Consult a lawyer for serious cases
