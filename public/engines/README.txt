Chess engines served by chessmasti.com
======================================

Every file in this directory is a build of the Stockfish chess engine,
compiled to JavaScript / WebAssembly so it can run inside your browser.
They are free software, released under the GNU General Public License
version 3 — the full license text is in COPYING.txt next to this file.

What these files are and where they come from:

  stockfish-16/  stockfish-16.1/  stockfish-17/
      Stockfish, copyright (C) T. Romstad, M. Costalba, J. Kiiski,
      G. Linscott and other contributors.
        https://github.com/official-stockfish/Stockfish
      JavaScript / WebAssembly builds from the stockfish.js project,
      copyright (C) Chess.com, LLC.
        https://github.com/nmrugg/stockfish.js
      The .nnue files are the neural-network evaluation weights
      published with the corresponding Stockfish releases.

  stockfish-11.js
      Multi-variant Stockfish by Daniel Dugovic and contributors,
        https://github.com/ddugovic/Stockfish
      compiled to JavaScript/WebAssembly by Niklas Fiekas.
